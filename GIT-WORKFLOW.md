# Git workflow

For github interactions use gh cli tool.

## Rules when working with git

1. Commit - always consists of max 7 words commit message with task nr prefix. eg. "AG-137 Order Detail page".
2. Messages and desc - Never add any "co-author: claude" or "author: claude" or similar signs.
3. PR - When create PR in github, use short description of changes.
4. When created a PR wait for gh actions to pass, if they fail try to fix it. Make  3 rounds and then if still failing or earlier if decision is needed - then escalate to human.
